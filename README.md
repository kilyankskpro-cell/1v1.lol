# 1v1.lol

Aucune installation : ouvre `index.html` (double-clic) dans Chrome, Edge ou Firefox.

- **Solo** : contre un bot, fonctionne sans aucun réseau.
- **Réseau local** : les deux joueurs ouvrent `index.html` sur le même réseau Wi-Fi/Ethernet (pas besoin d'Internet).
  1. L'hôte clique « Créer une partie » et envoie le code affiché à l'adversaire (message, clé USB…).
  2. L'adversaire clique « Rejoindre », colle le code, puis renvoie le code de réponse.
  3. L'hôte colle la réponse et clique « Lancer la partie ».

Commandes : ZQSD / WASD / flèches pour bouger, souris pour viser, clic pour tirer. Premier à 5 kills.
